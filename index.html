    1. Open this app in Google Chrome.
    2. Tap the three dots ⋮ in the top-right corner.
    3. Choose Install app or Add to Home screen.
    4. Confirm Install or Add.
    5. Open Honnasiri Honda from the new home-screen icon.

    If Chrome shows only “Add to Home screen”, use that option. The app opens in a standalone window. Keep the app URL saved for future access.
